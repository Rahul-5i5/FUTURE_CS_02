## Phishing Email Detection & Awareness System

This repository contains Task 2 submission for the Cyber Security Internship at Future Interns.

## Objective

To analyze phishing emails, identify suspicious indicators, and spread cybersecurity awareness.

## Tools Used

* Browser
* Email Samples
* Microsoft Word

## Activities Performed

* Phishing email analysis
* Sender verification
* Suspicious link detection
* Risk classification
* Awareness documentation

## Outcome

Identified phishing indicators and documented preventive measures against phishing attacks.
